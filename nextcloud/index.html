Personal Nextcloud setup

In September 2026 I set up a self-hosted Nextcloud instance at cloud.nhull.eu.

The aim was to have a small personal cloud for files, document sharing, browser-based editing and experimenting with Nextcloud administration.

Infrastructure

The server runs on Oracle Cloud's Always Free infrastructure in the Frankfurt region.

  • Ubuntu 24.04 LTS Minimal, ARM64
  • Oracle VM.Standard.A1.Flex
  • 2 OCPUs
  • 12 GB RAM
  • reserved public IPv4 address
  • Docker + Nextcloud All-in-One (AIO)

A separate 150 GB Oracle block volume is used for Nextcloud data. It is formatted as ext4 and mounted at /mnt/nextcloud-data.

Nextcloud's data directory is /mnt/nextcloud-data/nextcloud. The Ubuntu boot disk uses roughly another 50 GB, keeping the setup within Oracle's 200 GB Always Free block-storage allowance.

Networking

cloud.nhull.eu has an A record pointing to the server's reserved public IP.

The Oracle network consists of:

  • a dedicated VCN (nextcloud-vcn)
  • a public subnet (nextcloud-public-subnet)
  • a Network Security Group allowing TCP 80 for HTTP and certificate validation, TCP 443 for normal HTTPS access, and TCP 8443 for Nextcloud AIO administration

The server itself is administered over SSH using a private SSH key.

Nextcloud

Nextcloud is deployed using the official Nextcloud All-in-One Docker image.

The current setup includes:

  • Nextcloud Hub 26 Summer
  • PostgreSQL
  • Redis
  • Apache/Caddy
  • Client Push
  • EuroOffice
  • Imaginary
  • Nextcloud Whiteboard

The timezone is configured as Europe/Ljubljana.

The public Nextcloud instance is available at cloud.nhull.eu. The AIO administration interface is available separately on port 8443.

What it is used for

The instance can be used as a normal personal cloud:

  • private file storage
  • browser and mobile access
  • public or password-protected file sharing
  • separate user accounts
  • browser-based document editing
  • Nextcloud apps such as Calendar, Contacts, Tasks, Notes, Deck and Forms

Files are private by default and only become publicly accessible when an explicit share link is created.

Important

SSH private keys, Nextcloud/AIO passwords or passphrases, backup encryption passwords and other credentials or secrets are never committed to this repository.
